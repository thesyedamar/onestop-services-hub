# OneStop Services Hub

OneStop Services Hub is a service marketplace concept built with React, TypeScript, Vite, shadcn-ui, and Tailwind CSS. It is designed as a clean hub where users can discover and browse different services from one place.

## Highlights

- Service marketplace style interface
- Responsive layout for desktop and mobile users
- Modern component-based frontend
- Built with a production-friendly React stack

## Tech Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Run Locally

```bash
npm install
npm run dev
```

Then open the local development URL shown in your terminal.

## Project Focus

This project demonstrates modern frontend development for a service platform: organized UI, scalable components, and a structure that can grow into booking, listing, or customer-management features.
